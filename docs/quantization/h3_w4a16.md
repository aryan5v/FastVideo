# W4A16 for MiniMax-H3

Weight-only 4-bit storage with bf16/fp16 activations.
Implementation: `fastvideo/layers/quantization/w4a16_config.py`.

```python
from fastvideo.layers.quantization.w4a16_config import W4A16Config

fastvideo_args.transformer_quant = W4A16Config.for_minimax_h3()
```

This is a memory lane: weights are stored in 4-bit form and dequantized before
each dense GEMM. There is no fused W4A16 kernel in-tree yet.

Tests: `fastvideo/tests/ops/quantization/test_w4a16_config.py`.
